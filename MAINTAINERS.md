## Overview

This repository is owned and maintained by the **amazon-opensearch-clients** team in the
[aws GitHub organization](https://github.com/orgs/aws/teams/amazon-opensearch-clients).

Maintainers are members of that team. Team membership is managed through Amazon's internal
tooling (Abacus → GitHub team sync), which is the source of truth for who has write access
and review responsibility on this repo. If you're interested in contributing, see
[CONTRIBUTING](CONTRIBUTING.md).
